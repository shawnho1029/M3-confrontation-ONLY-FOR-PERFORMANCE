# Mon3tr 重構體定幀部署計算器

本項目提供了一個針對《明日方舟》薩卡茲肉鴿中，幹員 Mon3tr 搭配演出用香水定幀部署重構體的計算工具。通過精確計算攻擊動畫幀數與重構體生命流失幀的相對位置，幫助玩家避免因生命值回滿而導致 Mon3tr 不抬手治療的問題。

## 底層物理邏輯

### 1. 動畫長度與索敵時機
在《明日方舟》中，幹員攻擊時會以抬手時的攻速確定攻擊動畫長度，並在動畫播放結束時進入下一次索敵。
Mon3tr 的攻擊間隔屬性為 2.85 秒。在攻速 AS 下，第一A的動畫長度 L1（幀，30 fps）公式為：
`L1 = max(1, min(85, round(8550 / AS)))`
*註：動畫長度上限為 85 幀。*

### 2. 首次攻擊索敵限制
- 以 Mon3tr 部署時間點為第 0 幀，重構體在第 T_dep 幀部署。
- 重構體部署後從第 5 幀開始，每 3 幀流失 8 點生命值。流血幀 T_bleed 滿足：
  `T_bleed % 3 == (T_dep + 2) % 3`
- 首次索敵在第 32 幀。同幀內是「先索敵、後流血、再回血」。
- 為防止首次索敵時重構體是滿血狀態，首次索敵幀不能是流血幀：
  `32 % 3 != T_bleed % 3` 導出 `T_dep % 3 != 0`
  因此，**重構體部署幀 T_dep 固定排除 3 的倍數（即排除 3n 幀）**。

### 3. 後續攻擊索敵限制
第二次索敵發生在第 32 + L1 幀。後續索敵在同幀內為「先流血、後回血、再索敵」。
- **難救狀態**（重構體最大生命值在 [12000, 24000) 之間，香水每秒回血在 [120, 240) 之間）：
  重構體在流血後 1 幀即回滿。因此索敵幀必須與流血幀相同：
  `(32 + L1) % 3 == T_bleed % 3` 導出 `T_dep % 3 == L1 % 3`
- **有救狀態**（重構體最大生命值在 [8000, 12000) 之間，香水每秒回血在 [80, 120) 之間）：
  重構體在流血後 2 幀才回滿。因此索敵可以在流血後 0 幀或 1 幀：
  `T_dep % 3 != L1 % 3`

## 使用方法

1. **直接運行批次檔**：
   在 Windows 系統中，直接雙擊工作區中的 run.bat 檔案。

2. **輸入參數**：
   - **當前攻速**：例如輸入吃過被動後的初始攻速 `120`。
   - **生命值狀態**：
     - `1`：有救狀態（預設，直接按 Enter 即可）。
     - `2`：難救狀態。

3. **取得建議**：
   計算器會輸出：
   - Mon3tr 的動畫長度幀數。
   - 建議的部署時間規律（例如 3n+2 幀）。
   - 推薦的具體部署幀數示例（例如：第 2, 5, 8, 11, 14 幀）。
   - 攻速是否在持續治療推薦區間的驗證結果，若不在，會提示建議調整的鄰近攻速。
